# 练习：MCP 建单、代码检视与自动修复

## 目标

通过 MCP 创建 MR，触发机器检视，并使用修复 Skill 根据检视意见完成闭环。

## 输入

- 已完成 Petclinic 微闭环的本地分支。
- 可用的 MCP 授权。
- 可触发的代码检视规则和修复 Skill。

## 约束

- 禁止手敲 Git 命令替代 MCP 演示目标。
- 禁止手动修复缺陷绕过修复 Skill。
- 不暴露真实 Token、内部地址和敏感凭证。
- 创建 MR 前必须确认仓库、分支和工作区状态。

## 建议步骤

1. 在当前分支制造一个明确可检视的缺陷，例如违规打印或潜在空指针。
2. 让 CodeAgent 通过 MCP 创建 MR。
3. 检查 MR 描述是否包含需求、变更、测试和风险。
4. 触发机器检视并记录意见。
5. 调用修复 Skill 读取检视意见并生成最小修复。
6. Review 修复 diff。
7. 重新运行测试并更新证据包。

## 验收

- 有可访问 MR 链接。
- 有机器检视意见记录。
- 修复 diff 与测试结果可复核。
- 学员能说明 MCP 权限边界和脱敏处理。
