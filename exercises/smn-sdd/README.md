# 练习与大作业：SMN 告警插件 SDD

## 课堂练习目标

查询 dolphin-scheduler 的告警插件机制，产出 SMN 告警插件的 Proposal、Spec、Design、Tasks，并完成同伴 Review。

## 课后大作业目标

按照课堂过审的 Tasks 分步实现 SMN 告警插件，提交 MR，并提供完整证据链。

## 课堂约束

- 禁止生成 Java 业务代码。
- Design 必须覆盖 AK/SK 安全设计。
- Tasks 必须细化到类、配置、测试和验收命令。
- 文档必须引用至少两类现有项目事实或规范。

## 四阶文档建议结构

### Proposal

- 背景与业务目标。
- 范围与非范围。
- 关键风险。
- 交付物和里程碑。

### Spec

- 配置项：region、topic、ak、sk、消息模板等。
- 发送行为：成功、失败、超时、重试或不重试。
- 兼容性：现有告警配置和默认行为不破坏。
- 验收条件：可测试、可观察、可 Review。

### Design

- 现有插件机制和接入点。
- 类和模块设计。
- 配置流转和校验。
- AK/SK 注入、脱敏、日志和异常。
- 测试策略和测试桩。

### Tasks

- 按文件或类拆分任务。
- 每项任务包含目标、改动范围、验收方式。
- 明确任务顺序和回滚点。

## 课后提交物

- MR 链接。
- Proposal、Spec、Design、Tasks 链接或附件。
- 本地测试输出。
- 机器检视和人工 Review 处理记录。
- AI 协作过程证据：关键提示词、打回、修复记录。

## 安全红线

- 不提交真实 AK/SK、Token、生产地址和敏感日志。
- 不把真实凭证写入 Prompt、课件、截图或 MR 描述。
- 不绕过 Review 直接合并 AI 生成代码。
