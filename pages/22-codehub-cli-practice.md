# 练习：完成一次 MR 检视闭环
<BrandMark />
<PageNo current="20" />

<p class="codehub-practice-lead">基于刚刚完成的特性，按顺序完成以下 5 步</p>

<ol class="codehub-practice-steps"><li><span class="codehub-practice-index">01</span><h2>完成 CLI 认证</h2><p>在终端完成 CodeHub CLI 认证，确认当前账号可以访问目标仓库。</p></li><li><span class="codehub-practice-index">02</span><h2>Agent 完成提交</h2><p>让 Agent 检查刚刚完成的特性改动，并创建一次提交。</p></li><li><span class="codehub-practice-index">03</span><h2>自动创建 MR</h2><p>通过 CodeHub CLI 推送特性分支，并自动创建 MR。</p></li><li><span class="codehub-practice-index">04</span><h2>人工提交检视意见</h2><p>在 CodeHub 网页打开 MR，人工提交一条可执行的检视意见。</p></li><li><span class="codehub-practice-index">05</span><h2>获取意见并修复</h2><p>让 Agent 通过 CodeHub CLI 自动获取检视意见，修复后再次推送。</p></li></ol>
