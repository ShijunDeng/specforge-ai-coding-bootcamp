<p class="slide-subtitle course-review-lead">这门课围绕同一个目标展开：让 Agent 在真实项目中完成可验证的软件变更。</p>

<div class="course-review-grid">
  <section class="course-review-card course-review-card--agent">
    <header><span>01</span><div><small>AI CODING</small><h2>用好 Agent 工具链</h2></div></header>
    <ul>
      <li><b>说清任务</b><p>给出目标、上下文、边界和验收标准。</p></li>
      <li><b>按步骤执行</b><p>Explore → Plan → Code → Verify。</p></li>
      <li><b>扩展工具能力</b><p>用 Skill、CLI 和 MCP 加载知识、执行操作、连接系统。</p></li>
      <li><b>固化项目规则</b><p>用 AGENTS.md 记录仓库结构、常用命令和稳定约束。</p></li>
    </ul>
  </section>

  <section class="course-review-card course-review-card--sdd">
    <header><span>02</span><div><small>SPEC-DRIVEN DEVELOPMENT</small><h2>用规格推进复杂需求</h2></div></header>
    <ul>
      <li><b>先建立基线</b><p>从现有代码、项目规则和业务约束出发。</p></li>
      <li><b>逐层收敛</b><p>Spec → Design → Tasks，把需求变成可执行任务。</p></li>
      <li><b>边做边验证</b><p>按任务实现、测试和回写，在关键节点由人审核。</p></li>
      <li><b>保留交付证据</b><p>用运行结果、测试记录和变更内容完成验收。</p></li>
    </ul>
  </section>
</div>
